# {שם הספריה}

Skeleton repository for starting a new Flutter library project.

## Start a project

1. Replace `library_name` with the chosen Dart package name.
2. Replace `{שם הספריה}` and other placeholders in the documentation.
3. Update the package description, repository URL, and public API.
4. Run `flutter pub get` and `flutter analyze`.

The repository includes the library source, model instructions, general wiki
guidance, and a minimal runnable example. Tests, optional packages, product
notes, experiments, release records, and completed work items are deliberately
not part of the skeleton.

## Layout

- `lib/` - public library implementation.
- `example/` - minimal Flutter application.
- `wiki/` - reusable planning, validation, and workflow guidance.
- `.claude/`, `.cursor/` - model instructions and automation guidance.
